# Changelog

All notable changes to this project will be documented in this file.

## [1.2.6] - 2026-07-29

### Added
- 10 new auto-generated French arrow-word puzzles (Balade, Ferme, Ecole,
  Marche, Cuisine, Jungle, Cirque, Plage, Chalet, Verger), built by
  crossing a word+clue bank via a greedy fill algorithm. Bundled puzzle
  variety goes from 6 to 16; no existing puzzle was changed.
